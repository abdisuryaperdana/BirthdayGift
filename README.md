# 🎂 BirthdayGift

Website kado ulang tahun interaktif yang dibuat dengan HTML, CSS, dan JavaScript. Dibuat sebagai kejutan digital untuk orang tersayang.

🔗 **Demo langsung:** [birthday-gift-ulang-tahun.vercel.app](https://birthday-gift-ulang-tahun.vercel.app/)

---

## 📖 Tentang Proyek

BirthdayGift adalah website statis (tanpa backend) yang dirancang sebagai hadiah ulang tahun dalam bentuk digital. Cukup buka di browser, tanpa perlu instalasi apa pun.

> **[Isi di sini]** Tulis 1–2 kalimat tentang konsep website Anda, misalnya: ucapan, galeri foto, kejutan animasi, musik, dan sebagainya.

## ✨ Fitur

> **[Sesuaikan dengan fitur sebenarnya di website Anda]**

- 🎨 Tampilan responsif (nyaman dibuka di HP maupun komputer)
- 🎞️ Animasi dan interaksi menggunakan JavaScript
- 🖼️ Aset gambar/media tersimpan di folder `assets`
- 🚀 Di-deploy di Vercel sehingga mudah dibagikan lewat tautan

## 🛠️ Teknologi yang Digunakan

| Teknologi | Fungsi |
|-----------|--------|
| HTML5 | Struktur halaman |
| CSS3 | Tampilan dan animasi |
| JavaScript | Interaksi dan logika |
| Vercel | Hosting / deployment |

## 📁 Struktur Folder

```
BirthdayGift/
├── assets/        # Gambar, musik, atau media lain yang dipakai website
├── index.html     # Halaman utama
├── script.js      # Logika dan interaksi JavaScript
├── style.css      # Gaya tampilan (CSS)
└── README.md      # Dokumentasi proyek
```

## 🚀 Cara Menjalankan di Komputer

### Cara 1: Langsung buka file

1. Unduh atau clone repositori ini.
2. Buka file `index.html` dengan browser (Chrome, Edge, Firefox, dll).

### Cara 2: Dengan Git

```bash
git clone https://github.com/abdisuryaperdana/BirthdayGift.git
cd BirthdayGift
```

Lalu buka `index.html` di browser.

### Cara 3: Dengan local server (opsional, disarankan jika ada audio/video)

Jika memakai VS Code, pasang ekstensi **Live Server**, klik kanan `index.html`, lalu pilih **Open with Live Server**.

Atau dengan Python:

```bash
python -m http.server 8000
```

Kemudian buka `http://localhost:8000` di browser.

## ✏️ Cara Menyesuaikan Isi

1. **Teks / ucapan:** ubah di `index.html` (atau di `script.js` bila teks dibuat lewat JavaScript).
2. **Tampilan / warna / font:** ubah di `style.css`.
3. **Foto, musik, atau media:** ganti atau tambahkan file di folder `assets`, lalu pastikan nama file pada kode sama dengan nama file aslinya.
4. **Perilaku / animasi:** ubah di `script.js`.

## 🌐 Deployment

Website ini di-deploy menggunakan [Vercel](https://vercel.com/):

1. Push perubahan ke GitHub (branch `master`).
2. Vercel akan otomatis membangun ulang dan memperbarui website jika repositori sudah terhubung.
